1. INTRODUCTION                                   *simpleminimap-introduction*

SimpleMinimap opens a fixed-width window at the far right (or configured left)
of the current tab and renders a compact overview of the active normal buffer.
Vim9 script owns window state, events, highlighting and navigation.  A
long-running Rust job renders bounded line samples into Braille, block or ASCII
density glyphs.

The plugin supports Vim 9 only.  It does not support Neovim.

==============================================================================
2. REQUIREMENTS                                   *simpleminimap-requirements*

- Vim 9.0 or newer.
- Vim compiled with +job and +channel.
- Rust 1.88 or newer and Cargo when building from source.
- UTF-8 is recommended for the default Braille renderer.

Run: >
  :echo has('job')
  :echo has('channel')
<
Both values must be 1.

==============================================================================
3. COMMANDS                                           *simpleminimap-commands*

:SimpleMinimap                                      *:SimpleMinimap*
        Toggle the minimap for the current tab.

:SimpleMinimapOpen                                  *:SimpleMinimapOpen*
        Open the minimap.  Does nothing when this tab already owns one.

:SimpleMinimapClose                                 *:SimpleMinimapClose*
        Close the minimap in the current tab.

:SimpleMinimapRefresh                               *:SimpleMinimapRefresh*
        Render immediately, bypassing the normal edit debounce and the
        render signature cache.

:SimpleMinimapRefresh!
        Force every live tab session to render, without changing the current
        tab or window. Closed and invalid sessions are pruned, not reopened.

:SimpleMinimapFocus                                   *:SimpleMinimapFocus*
        Focus the minimap window.  Open it first when necessary.

:SimpleMinimapPin                                       *:SimpleMinimapPin*
        Lock this tab's minimap to its current source split.  Entering other
        splits no longer changes the rendered source.

:SimpleMinimapUnpin                                   *:SimpleMinimapUnpin*
        Resume following the active eligible split.

:SimpleMinimapTogglePin                         *:SimpleMinimapTogglePin*
        Toggle the source lock.  A lost or ineligible pinned split is safely
        unlocked and replaced by another eligible window.

:SimpleMinimapResize [width]                         *:SimpleMinimapResize*
        Set every open minimap to 6..80 columns. The option is global, so
        background tab sessions change together and newly opened sessions use
        the same width. With no argument, report the configured width.

:SimpleMinimapStyle [style]                           *:SimpleMinimapStyle*
        Set "braille", "blocks" or "ascii" and redraw all sessions.  With
        no argument, cycle to the next style.

:SimpleMinimapRestart                               *:SimpleMinimapRestart*
        Restart the renderer while preserving all minimap sessions.

:SimpleMinimapHealth                                *:SimpleMinimapHealth*
        Show categorized Vim, daemon, protocol, session and configuration
        checks: the daemon path and version, the negotiated protocol against
        the one this plugin expects, the measured backend round-trip latency,
        the request deadline and how many requests have expired, the restart
        budget and crash-loop breaker state, search projection support,
        per-session render statistics and the last backend error.

        It never blocks: the daemon version is probed with a job and reported
        as "probing…" until it arrives, so running this command against a
        wedged daemon cannot itself hang.  The probe is cached against the
        binary's path, modification time and size, so the rebuild this command
        recommends is picked up on the next |:SimpleMinimapHealth| rather than
        reported from a cache for the rest of the session;
        |:SimpleMinimapRestart| discards the cache outright.

        It also reports configuration problems: a 'encoding' that cannot
        represent the configured render style, and any g:simpleminimap_*
        variable that is not an option this plugin reads -- a misspelled option
        name is otherwise ignored in silence for ever.
        |simpleminimap#UnknownOptions()| returns that list on its own.

                                          *simpleminimap#UnknownOptions()*
                                          *simpleminimap#KnownOptions()*
        simpleminimap#UnknownOptions() returns the sorted list of
        g:simpleminimap_* variables this plugin does not read, without the
        rest of the report -- useful from a configuration test of your own.
        simpleminimap#KnownOptions() returns the sorted list of every option
        name the plugin does read.

:SimpleMinimapDebug                                 *:SimpleMinimapDebug*
        Echo the complete internal state dictionary.

4. MAPPINGS                                           *simpleminimap-mappings*

The plugin exposes one target per command:      *<Plug>(simpleminimap-toggle)*

  <Plug>(simpleminimap-toggle)        :SimpleMinimap
  <Plug>(simpleminimap-open)          :SimpleMinimapOpen
  <Plug>(simpleminimap-close)         :SimpleMinimapClose
  <Plug>(simpleminimap-focus)                    *<Plug>(simpleminimap-focus)*
  <Plug>(simpleminimap-pin)                        *<Plug>(simpleminimap-pin)*
  <Plug>(simpleminimap-unpin)         :SimpleMinimapUnpin
  <Plug>(simpleminimap-toggle-pin)          *<Plug>(simpleminimap-toggle-pin)*
  <Plug>(simpleminimap-refresh)       :SimpleMinimapRefresh
  <Plug>(simpleminimap-refresh-all)   :SimpleMinimapRefresh!
  <Plug>(simpleminimap-style)         :SimpleMinimapStyle
  <Plug>(simpleminimap-restart)       :SimpleMinimapRestart
  <Plug>(simpleminimap-health)        :SimpleMinimapHealth
  <Plug>(simpleminimap-log)           :SimpleMinimapLog

The pin target is idempotent: invoking it while already pinned keeps the pin.
Use the toggle-pin target for a mapping that alternates between both states.

When |g:simpleminimap_set_default_mapping| is enabled and <Leader>m is free,
the plugin maps <Leader>m to that <Plug> target.

Inside the minimap buffer:

  <CR>        Jump to the midpoint of the represented source range.
  <Space>     Preview the range while retaining minimap focus.
  <LeftMouse> Jump to the clicked range.  Dragging from inside the viewport
              band drags the band itself, so the minimap works as a scrollbar;
              dragging from outside it previews continuously as before.
  Mouse wheel Scroll the tracked source window.
  r           Refresh immediately.
  s           Cycle the render style.
  p           Pin or unpin the current source split.
  + / -       Grow or shrink every tab's minimap by two columns.
  <Esc>       Return focus to the tracked source window.
  q           Close the minimap.

Mouse actions require the relevant Vim mouse events, normally via: >
  set mouse=a
<

5. OPTIONS                                             *simpleminimap-options*

All options must be set before the plugin is loaded.

*g:simpleminimap_width*
        Number, default 18. Minimap width, clamped to 6..80. Runtime resize
        commands apply this global value to every open tab session.

*g:simpleminimap_max_columns*
        Number, default 120.  Maximum logical source columns analyzed per
        sample, clamped to 20..1000.

*g:simpleminimap_debounce*
        Number, default 80.  Delay in milliseconds after edits, clamped to
        0..2000.  Zero renders synchronously from the Vim event callback, while
        the actual compression still runs in the Rust job.

*g:simpleminimap_render_style*
        String, default "braille".  Accepted values are "braille", "blocks"
        and "ascii".  Unknown values fall back to "braille".

*g:simpleminimap_sampling*
        String, default "adaptive".  "adaptive" samples the start, midpoint
        and end of each vertical band and keeps the most informative line.
        "uniform" always uses the midpoint.  Both modes remain bounded.

*g:simpleminimap_side*
        String, default "right".  Use "left" to create new minimap splits at
        the far left of a tab.

*g:simpleminimap_daemon_path*
        String, default empty.  Absolute path to simpleminimap-daemon.  With an
        empty value the plugin searches its lib/, target/release/,
        target/debug/, runtimepath lib/ directories and $PATH.

*g:simpleminimap_show_statusline*
        Boolean number, default 1.  Show a small SimpleMinimap statusline.

                                            *simpleminimap#StatuslineExpr()*
        The minimap owns the window-local 'statusline', 'wincolor' and
        'winfixwidth' of its own window and re-applies them on BufWinEnter and
        WinEnter, so a statusline manager that rewrites &l:statusline for every
        window cannot blank the minimap title.  A statusline manager that wants
        to cooperate rather than be corrected can ask for the canonical value
        instead of hard-coding it: >

          if &filetype ==# 'simpleminimap'
            &l:statusline = simpleminimap#StatuslineExpr()
          endif
<       It returns an empty string when |g:simpleminimap_show_statusline| is 0.

*g:simpleminimap_show_signs*
        Boolean number, default 1.  Project signs placed in the tracked buffer
        by Git, LSP, lint and other integrations onto minimap rows.  Signs are
        classified by name into error, warning, info, git add/change/delete
        and other categories; when several signs share a minimap row the most
        severe category wins.

*g:simpleminimap_show_search*
        Boolean number, default 1.  Project the active 'hlsearch' matches of
        the last search pattern onto minimap rows.  Requires |matchbufline()|
        (Vim 9.1.0009 or newer); silently disabled otherwise.

        A minimap row is marked when any line in its range matches, so the
        projection reads each row's range only until its first hit and stops
        there; buffer size is no longer a reason to skip it.  A pattern that
        matches nowhere in a buffer of several million lines exhausts the scan
        budget instead: the rows decided so far are shown and the statusline
        gains a "~" marker to say the overview is incomplete.

*g:simpleminimap_shading*
        Boolean number, default 1.  Shade every rendered minimap cell by its
        code density using text properties: sparse cells use
        |SimpleMinimapShadeLow|, average cells |SimpleMinimapShadeMid| and
        dense cells |SimpleMinimapShadeHigh|.  Requires +textprop; silently
        disabled otherwise.

*g:simpleminimap_ignore_filetypes*
        List of strings, default empty.  Windows whose buffer 'filetype' is in
        the list are not eligible source windows.

*g:simpleminimap_auto_close*
        Boolean number, default 0.  Close the minimap when its tab has no normal
        editable window.  With zero, the minimap remains and shows a message.

*g:simpleminimap_auto_open*
        Boolean number, default 0.  Open a minimap on VimEnter and TabEnter
        when an eligible source window exists.

*g:simpleminimap_auto_restart*
        Boolean number, default 1.  Retry an unexpectedly exited backend up to
        three times per rolling 60-second window, with 100/350/1000ms backoff.
        Spending that budget trips the crash-loop breaker: the failure is
        reported once and nothing is respawned again -- not on a timer and not
        on the next render -- until |:SimpleMinimapRestart| re-arms it.  The
        budget is deliberately NOT reset by a successful render, because a
        daemon that crashes after every render makes progress every time and
        would otherwise be respawned for ever.
        This governs every automatic restart, including the one triggered by
        repeated request timeouts (see |g:simpleminimap_request_timeout_ms|):
        those spend the same budget, and setting this option to 0 leaves a
        wedged daemon alone instead of silently replacing it.

*g:simpleminimap_request_timeout_ms*
        Number, default 5000, clamped to 100..600000.  How long to wait for a
        render reply before giving up on it.  A daemon that accepts input and
        stops answering -- wedged, stopped, blocked on a slow filesystem -- is
        still a live process with a healthy |job_status()|, so without a
        deadline the minimap keeps showing pre-edit content indefinitely.  On
        expiry the request is dropped and the minimap says so; two consecutive
        expiries restart the daemon, out of the same restart budget a crash
        spends (see |g:simpleminimap_auto_restart|).  A daemon that answers the
        handshake and then goes silent for ever is therefore given up on after
        three restarts rather than replaced for the rest of the session, and
        |:SimpleMinimapHealth| reports the breaker as tripped "(no response)".
        Set to 0 to disable the deadline, which |:SimpleMinimapHealth| then
        reports as a warning.

*g:simpleminimap_mouse_scroll_lines*
        Number, clamped to 1..50.  Source lines scrolled per mouse wheel event
        over the minimap.  When left unset it follows the vertical component of
        'mousescroll', so the wheel moves the source at the same rate over the
        minimap as over the code; it falls back to 3 where 'mousescroll' does
        not exist or is set to ver:0 ("half a window", which has no fixed line
        count).

*g:simpleminimap_drag_thumb*
        Boolean number, default 1.  Pressing on the highlighted viewport band
        and dragging scrolls the source window, like dragging a scrollbar
        thumb; the source cursor is left where the scroll leaves it.  Pressing
        anywhere else still jumps to that band, and a press that never becomes
        a drag behaves the same either way.  Set to 0 to make every drag
        preview the band under the pointer, as before this option existed.

        Because Vim resolves mappings against the buffer that owns focus when
        the key is typed, a click that arrives while the source window is
        current is not delivered to the minimap; the gesture is then anchored
        on the first drag event instead.

*g:simpleminimap_set_default_mapping*
        Boolean number, default 1.  Install <Leader>m only when it is unused.

*g:simpleminimap_debug*
        Boolean number, default 0.  Emit diagnostic messages to |:messages|.

7. DESIGN                                               *simpleminimap-design*

One session is maintained per tab.  The session follows the most recently
entered eligible normal window in that tab, unless pinned with
|:SimpleMinimapPin|.  A pin belongs to the source window rather than its
buffer: wiping that buffer keeps the pin when Vim loads another eligible
buffer into the same window.  TextChanged, TextChangedI,
BufWritePost, WinResized, WinScrolled and tabstop changes schedule an update.

The source is divided into at most one group per minimap screen row.  A group
contains four representative source lines.  Adaptive mode chooses among three
bounded candidates per vertical band.  Vim normalizes source characters to
actual display cells, including tabs, CJK, emoji and zero-width combining
characters.  The Rust daemon then maps non-whitespace content to a 2-by-4
Braille cell or an equivalent density character.  Protocol size remains
controlled by minimap height and g:simpleminimap_max_columns rather than total
file length.

Every request has a monotonically increasing ID.  Vim applies a response only
when it is still the newest request for that session.  It waits for the READY
handshake, validates response ranges and dimensions, and coalesces obsolete
requests.  Unexpected backend exits use bounded automatic restart attempts.
In the daemon a new begin record supersedes an unfinished request instead of
failing, which keeps recovery simple after interrupted writes.

Each request body is hashed (|sha256()|) before it is sent.  When the
signature matches the last applied render, the daemon round-trip is skipped
and only the viewport, cursor, sign and search overlays are refreshed.
|:SimpleMinimapRefresh| bypasses this cache.

Sign and search projection are overlays implemented with |matchaddpos()| in
the minimap window; they never modify the rendered text and are recomputed
lazily from cached state on cursor movement and |CursorHold|.

With protocol version 2 the daemon reports one density digit per rendered
cell alongside each row.  Vim converts contiguous runs of equal density into
text properties so that dense code appears brighter than sparse code.  The
minimap statusline additionally shows the cursor position as a percentage of
the source buffer.

8. TROUBLESHOOTING                             *simpleminimap-troubleshooting*

"daemon not found"
        Run install.sh or install.ps1 in the plugin root, or set
        g:simpleminimap_daemon_path to an executable built for this machine.

Blank or missing Braille glyphs
        Set: >
          let g:simpleminimap_render_style = 'blocks'
<       Use "ascii" for terminals without Unicode block characters.

The minimap does not follow a window
        Only normal buffers with an empty 'buftype' are followed.  Help,
        terminal, quickfix and plugin scratch windows are intentionally skipped.

Inspect state
        Run |:SimpleMinimapHealth| and |:SimpleMinimapDebug|.  Enable
        g:simpleminimap_debug and inspect |:messages| for job diagnostics.

Backend stopped or protocol mismatch
        Run |:SimpleMinimapHealth|, then |:SimpleMinimapRestart| after fixing
        the reported daemon path or rebuilding it with install.sh/install.ps1.

"daemon is out of date"
        The plugin files were updated without rebuilding the daemon, so the
        two no longer agree on the protocol.  Health reports it as
        "[FAIL] daemon protocol: daemon vN, plugin expects vM".  Run
        install.sh (or install.ps1), then |:SimpleMinimapRestart|.

The minimap froze but the daemon looks fine
        A daemon that accepts input and stops answering is a live process.
        Health reports the expired-request count next to the deadline; see
        |g:simpleminimap_request_timeout_ms|.  Repeated crashes -- and repeated
        timeouts -- trip the crash-loop breaker, which Health reports as
        tripped, with the reason, and |:SimpleMinimapRestart| clears.

DAEMON SUPERVISION                                    *simpleminimap-daemon*

The Rust daemon is supervised by this plugin directly, in
autoload/simpleminimap.vim.  The suite's shared supervisor is vendored
alongside it at autoload/simpleminimap/core.vim and is not what runs here; see
|simpleminimap-simplecore|.

What the supervision guarantees:

- Liveness is always read from |job_status()|. job_start() returns a job
  object even when the exec itself failed, so a daemon that cannot start is
  never mistaken for one that is running.
- A superseded daemon's late exit callback cannot clear the state of the
  replacement that already took its place.
- Output still queued when you stop the daemon is discarded, so an explicit
  stop cannot be undone by an event that was already in flight.
- A daemon that dies is restarted automatically with 100/350/1000ms backoff,
  at most three times per rolling 60-second window.  Spending that budget
  trips the crash-loop breaker: the failure is reported once and no further
  process is started, by any path, until |:SimpleMinimapRestart| re-arms it.
  See |g:simpleminimap_auto_restart|.
- Requests are correlated to replies by id and time out, so a daemon that
  accepts input and stops answering cannot leave the minimap stale behind a
  healthy-looking process.  See |g:simpleminimap_request_timeout_ms|.
- A restart forced by repeated timeouts spends the same budget as one forced
  by a crash, so "stops answering" is as bounded as "keeps dying": there is one
  budget, not one per failure mode, and it is never refunded by switching
  between them.

:SimpleMinimapHealth
        Report daemon path and version, run state, protocol version, measured
        round-trip latency, the request deadline and how many requests have
        expired, the restart budget and whether the crash-loop breaker has
        tripped, plus per-session render statistics and the last backend
        error.

:SimpleMinimapRestart
        Stop the daemon and start a fresh one. Clears the crash-loop breaker,
        so this is the way back after repeated failures.

                                                      *:SimpleMinimapLog*
:SimpleMinimapLog
        Open the daemon transcript in a scratch buffer: start and exit events,
        restarts, protocol handshakes, send failures and stderr.

DAEMON COMMAND LINE                                 *simpleminimap-daemon-cli*

The daemon takes no arguments in normal use: the plugin starts it and speaks a
line-oriented, TAB-separated protocol over its stdin and stdout.  The daemon
announces "READY <protocol>", answers "P <id>" with "PONG <id> <protocol>", and
answers a render request (a "B" header, one "G" record per row band, then "E")
with a "B" header, one "R" record per rendered row, and "E"; a request it
cannot serve is answered with "X <id> <reason>".  For diagnosis it also
answers: >

  simpleminimap-daemon --version
  simpleminimap-daemon --help
  simpleminimap-daemon --self-test
<
--self-test checks the daemon can run and prints "ok".
install.sh runs it on the freshly built binary before replacing a working one,
so a build that compiles but does not work never reaches lib/.

Every daemon in the simple* suite answers these three the same way.

VENDORED SUPERVISOR                                 *simpleminimap-simplecore*

The suite's shared daemon supervisor in autoload/simpleminimap/core.vim, and
the test harness beside it, are vendored from the shared .simplecore bundle
rather than written here — each plugin carries its own copy so that installing
this plugin alone is enough.  Do not edit those files in place: >

  make core-verify
<
checks each of them against the sha256 recorded in .simplecore.manifest and
fails the build when one has drifted.  `make check` depends on it.

The bundle lives at https://github.com/beamiter/simplecore.  To change the
supervisor, clone it beside the plugins, edit it there, and re-vendor: >

  git clone https://github.com/beamiter/simplecore ../.simplecore
  ../.simplecore/vendor.sh
<
